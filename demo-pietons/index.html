Détection de piétons pour l'aide à la conduitePedestrian detection for driver assistance

Modèle YOLOv8n qui détecte les piétons et les cyclistes ou motards dans des scènes de rue (projet PIF6004, UQTR). La version 2 part de poids pré-entraînés sur COCO et atteint un mAP@0,5 de 0,86 sur un jeu de test séparé, contre 0,55 pour la version remise. Le modèle s'exécute dans votre navigateur : vos images ne quittent pas votre appareil.

YOLOv8n detecting pedestrians and riders in street scenes (course project, UQTR). Version 2 is fine-tuned from COCO-pretrained weights and reaches mAP@0.5 = 0.86 on a held-out test set, versus 0.55 for the submitted version. It runs in your browser: your images never leave your device.

  • Données : 75 images de rue annotées à la main (CVAT), 2 classes (pedestrian, rider). v2 : 48 images d'entraînement, 12 de sélection, 14 de test.
  • Data: 75 hand-annotated street images (CVAT), 2 classes (pedestrian, rider). v2: 48 training, 12 selection and 14 test images.
  • Exécution : ONNX Runtime Web (WebAssembly), seuil d'IoU de 0,7 pour la suppression des doublons.
  • Inference: ONNX Runtime Web (WebAssembly), non-maximum suppression at IoU 0.7.
  • Les scores mesurés sur 14 images de test restent indicatifs : le jeu de données est petit.
  • Scores measured on 14 test images are indicative only: the dataset is small.
